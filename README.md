# Final-Year-Project
A Deepfake Detection system using Deep Learning. Provides Image and Video Prediction capabilities. The Web App provides results of the media which includes a Classification Result, a Confidence Score, a Heatmap and Textual Explainability.

File types accepted: JPG, JPEG, PNG, MP4
